# LIMEN — dirección del catálogo inicial

Fecha de recuperación: 2 de octubre de 2026.

## Regla de producto

Una plantilla nueva no es Origin 01 con otra fotografía o paleta. Cada universo debe aportar una
estructura narrativa, composición, movimiento, tipografía, iconografía y atmósfera propias. Las
variantes curadas existen dentro de una plantilla; no reemplazan la creación de un segundo renderer.

## Catálogo de salida propuesto

1. **Origin 01:** elegante, narrativa y emocional. Ya existe como primera plantilla real.
2. **Garden 01:** luminosa, natural, delicada y premium. Es la siguiente candidata a diseño y
   validación.
3. **Celebración:** joven, dinámica y festiva. Se mantiene como tercera dirección para ampliar el
   catálogo sin repetir el tono de Origin.

Editorial / Quiet Luxury, Modern Minimal, Coquette, Urban y Fantasy se conservan como investigación
posterior. Las exploraciones nocturnas u oscuras no avanzan automáticamente: deberán revisarse porque
varias pruebas anteriores resultaron demasiado oscuras para la dirección comercial buscada.

## Señal distintiva de Garden 01

La referencia que debe recuperarse antes del diseño definitivo es la composición con fotografías
colgantes. No se trata de decorar una galería existente: ese gesto debe integrarse al relato visual de
Garden y admitir fotografías reales con buena legibilidad, encuadre controlado y comportamiento
mobile-first.

Garden debe evitar:

- fondos excesivamente oscuros;
- convertirse en una variante verde de Origin 01;
- repetir las mismas tarjetas, orden, animaciones y transiciones;
- ornamentos genéricos o acumulados sin función narrativa;
- movimiento rápido o repetitivo de abajo hacia arriba.

Antes de implementarla se reconstruirá el boceto visual aprobado o una referencia equivalente para
confirmar la dirección artística. La base de datos no condicionará su composición: persistirá un
contrato de plantilla versionado, mientras Garden conservará el control de su propio renderer.

## Garden 01 aprobado

La dirección visual aprobada el 8 de octubre de 2026 combina marfil luminoso, verde salvia y acentos
dorado mate. Las fotografías colgantes son el gesto principal: funcionan como parte del relato y no
como una galería añadida. El número 15 se integra como elemento arquitectónico, mientras la
información práctica se resuelve con papel claro, jerarquía editorial y ornamentación contenida.

La primera entrega incorpora el contrato versionado, una demostración pública independiente y su
acceso desde el catálogo. La edición de Garden dentro de Studio queda para la siguiente etapa, una
vez validado el renderer real, para no acoplar el nuevo universo al modelo específico de Origin 01.
